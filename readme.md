# Sneed's Infernum Case

This is a coffin-esque 3D-printed case for the Infernum with a 0-degree typing angle. It uses the stock Infernum plate and M2 self-tapping screws.

The case has a sealed compartment for 1/4 oz wheel weights, accessed from the underside. Refer to the images in this repo for a render showing how they should fit in this space. This requires one M2 heat-set insert and one M2 fastener 4mm to 6mm in length. The 3mf file contains a plate with this compartment filled if you do not plan on using wheel weights - if you are creating your own print file, you would want to add primitives to fill the compartment.


## Case Files

Case files are located in this repository - the 3mf is my personal print file that uses fuzzy skin, scarfed seams, and a Hilbert curve top surface.

If you are configuring your own print, you should be able to go without using supports on most of the geometry, though I highly recommend it for the compartment door and lower recess that inferfaces with the door.

## Bill of Materials and Assembly
### BOM

| Part | Spec | Qty | Note |
| --- | --- | --- | --- |
| Plate screws | M2 self-tapping, 5-6mm | 4 | |
| Fasteners | M2 heat-set insert and M2 pan head/flat head screw, 4-6mm | 1 each | *To secure the weight compartment door. There is not a relief or counterbore for the screw head, so use the flattest you can find* |
| Feet | SKUF | 4 | *SKUF can be obtained from keeb.io in the US* |
| Weights | 1/4 oz, roughly 16 x 18.5 x 3.75 mm | up to 8 | *Recommended to use max number of weights to completely fill the space.* |
